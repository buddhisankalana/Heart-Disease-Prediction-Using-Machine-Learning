# Heart Disease Prediction Using Machine Learning

## Project Overview
This project aims to predict the presence of heart disease using machine learning classification techniques.  
The study focuses on analyzing patient health data, building multiple ML models, and identifying key medical features that contribute to heart disease risk.

This project was developed as part of a **Machine Learning final assignment** and is suitable for **academic evaluation as well as portfolio showcasing**.

---

## Objectives
- To preprocess and analyze heart disease data
- To build and compare multiple machine learning classification models
- To evaluate model performance using accuracy metrics
- To identify important features influencing heart disease prediction

---

## Dataset
- **Dataset Name:** Heart Disease Dataset  
- **Description:** Contains medical attributes such as age, sex, cholesterol level, blood pressure, and heart disease diagnosis.
- **Target Variable:** Presence of heart disease (Binary Classification)

---

## Methodology
1. Data loading and exploration
2. Data preprocessing and feature selection
3. Train–test data splitting
4. Model training using multiple classification algorithms
5. Performance evaluation and comparison
6. Feature importance analysis

---

## Machine Learning Models Used
- Logistic Regression
- Random Forest Classifier
- Additional classification models for comparison

---

## Results & Insights
- Compared multiple models based on accuracy
- Random Forest achieved strong predictive performance
- Identified key medical features contributing to heart disease
- Demonstrated the effectiveness of machine learning in healthcare prediction tasks
